ข้อตกลงการใช้งานและนโยบายความเป็นส่วนตัว

ระบบจัดการห้องเช่า · มีผลตั้งแต่ 27 พฤศจิกายน 2569 · ติดต่อ LINE @287yhkhu
ข้อตกลงการใช้งานนโยบายความเป็นส่วนตัวข้อความแจ้งผู้เช่า

ส่วนที่ 1: ข้อตกลงการใช้งาน

ข้อตกลงนี้เป็นข้อตกลงระหว่างทีมงานระบบจัดการห้องเช่า (LINE OA @287yhkhu) ("ผู้ให้บริการ") กับผู้ซื้อหรือผู้ใช้ระบบ ("ลูกค้า") การชำระเงินหรือเริ่มใช้งานระบบถือว่าลูกค้าได้อ่านและยอมรับข้อตกลงนี้แล้ว

1. แพ็กเกจและขอบเขตบริการ

A: แบบสมาชิกB: แบบซื้อขาด (Google Sheet)C: ระบบส่วนตัว (GitHub + Supabase)
ที่ตั้งระบบและข้อมูลเซิร์ฟเวอร์ของผู้ให้บริการGoogle Drive ในบัญชีของลูกค้าบัญชี GitHub และ Supabase ของลูกค้า
จำนวนห้องสูงสุด20 ห้องต่อบัญชี50 ห้อง100 ห้อง
รูปมิเตอร์เก็บ 12 เดือน แล้วลบอัตโนมัติอยู่ใน Drive ของลูกค้า ไม่ลบอัตโนมัติลบอัตโนมัติเมื่อครบ 2 ปี
การอัปเดตฟีเจอร์อัปเดตให้อัตโนมัติได้เวอร์ชันที่ซื้อได้เวอร์ชันที่ซื้อ
การดูแลหลังขายตลอดอายุสมาชิก ผ่าน LINEแก้บั๊กฟรี 3 เดือนหลังติดตั้งแก้บั๊กฟรี 3 เดือนหลังติดตั้ง
  • โปรลองใช้ 3 เดือน 199 บาท ใช้ได้เฉพาะลูกค้าใหม่ 1 สิทธิ์ต่อหอพัก
  • "แก้บั๊ก" หมายถึงแก้ให้ระบบทำงานได้ตามที่ออกแบบไว้ ไม่รวมการเพิ่มฟีเจอร์ใหม่ หรือแก้ปัญหาที่เกิดจากการที่ลูกค้าแก้ไขโค้ด หัวตาราง ชีต หรือการตั้งค่าเอง

2. การชำระเงินและการคืนเงิน

  1. ลูกค้าชำระเงินล่วงหน้าตามราคาที่ประกาศ ณ วันที่สั่งซื้อ
  2. ไม่รับคืนเงินหลังเปิดบัญชี (แพ็กเกจ A) หรือหลังติดตั้งแล้ว (แพ็กเกจ B และ C)
  3. แพ็กเกจ A: ถ้าไม่ต่ออายุ บัญชีจะถูกพักการใช้งาน ข้อมูลยังเก็บไว้ครบ ต่ออายุแล้วใช้ต่อได้ทันที

3. หน้าที่ของลูกค้า

  1. เก็บรักษาอีเมล รหัสผ่าน หรือ PIN ของตนเองเป็นความลับ การใช้งานผ่านบัญชีของลูกค้าถือเป็นการกระทำของลูกค้า
  2. ใช้ระบบเพื่อจัดการห้องเช่าอย่างถูกกฎหมายเท่านั้น
  3. ลูกค้าเป็นผู้รับผิดชอบข้อมูลผู้เช่าที่บันทึกในระบบ ในฐานะ "ผู้ควบคุมข้อมูลส่วนบุคคล" ตาม พ.ร.บ. คุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 ได้แก่ แจ้งผู้เช่าว่าเก็บข้อมูลอะไร เพื่ออะไร เก็บเท่าที่จำเป็น และลบเมื่อหมดความจำเป็น
  4. แพ็กเกจ B และ C: ลูกค้าดูแลบัญชี Google, GitHub และ Supabase ของตนเอง รวมถึงสำรองข้อมูลเป็นประจำ ผู้ให้บริการเข้าถึงและกู้คืนข้อมูลในบัญชีของลูกค้าไม่ได้

4. ข้อจำกัดความรับผิด

  1. ผู้ให้บริการพยายามให้ระบบทำงานต่อเนื่องและถูกต้อง แต่ไม่รับประกันว่าระบบจะไม่มีข้อผิดพลาดหรือไม่หยุดชะงักเลย ลูกค้าควรตรวจสอบยอดบิลก่อนส่งให้ผู้เช่าทุกครั้ง
  2. ผู้ให้บริการไม่รับผิดชอบความเสียหายที่เกิดจากบริการของบุคคลที่สามขัดข้องหรือเปลี่ยนนโยบาย (Google, GitHub, Supabase, LINE, ผู้ให้บริการอินเทอร์เน็ต) จากการที่ลูกค้าแก้ไขระบบเอง หรือเปิดเผยรหัสผ่านหรือ PIN และจากเหตุสุดวิสัย
  3. ความรับผิดรวมของผู้ให้บริการไม่เกินจำนวนเงินที่ลูกค้าชำระในรอบบริการล่าสุด

5. การระงับบริการ

ผู้ให้บริการอาจระงับบัญชีแพ็กเกจ A ได้ ถ้าพบว่ามีการใช้งานผิดกฎหมาย ใช้งานที่สร้างภาระผิดปกติแก่ระบบ หรือพยายามเจาะระบบ โดยจะแจ้งลูกค้าทาง LINE ก่อน เว้นแต่เป็นกรณีเร่งด่วน

6. การยุติการให้บริการ (แพ็กเกจ A)

ถ้าผู้ให้บริการจะยุติการให้บริการ จะแจ้งล่วงหน้าอย่างน้อย 90 วัน และส่งข้อมูลของลูกค้าคืนเป็นไฟล์

7. ทรัพย์สินทางปัญญา

  1. ซอร์สโค้ดและการออกแบบระบบเป็นของผู้ให้บริการ
  2. ลูกค้าแพ็กเกจ B และ C ได้สิทธิ์ใช้งานระบบสำหรับกิจการของตนเองได้ไม่จำกัดเวลา แต่ห้ามขายต่อ แจกจ่าย หรือนำไปติดตั้งให้ผู้อื่น
  3. ข้อมูลที่ลูกค้าบันทึกเป็นของลูกค้า

8. การแก้ไขข้อตกลง

ผู้ให้บริการอาจแก้ไขข้อตกลงนี้ และจะแจ้งทาง LINE OA ก่อนมีผลอย่างน้อย 15 วัน การแก้ไขจะไม่ลดสิทธิ์ที่ลูกค้าชำระเงินไปแล้วในรอบปัจจุบัน

9. กฎหมายที่ใช้บังคับ

ข้อตกลงนี้ใช้กฎหมายไทย

ส่วนที่ 2: นโยบายความเป็นส่วนตัว

ทีมงานระบบจัดการห้องเช่า ("เรา") ให้ความสำคัญกับข้อมูลส่วนบุคคล นโยบายนี้อธิบายว่าเราเก็บ ใช้ และดูแลข้อมูลอย่างไร ตาม พ.ร.บ. คุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562

1. ข้อมูลของลูกค้า (เจ้าของหอพัก): เราเป็นผู้ควบคุมข้อมูล

ข้อมูลใช้เพื่อฐานทางกฎหมาย
ชื่อ ชื่อ LINE และข้อความที่คุยกับเราตอบคำถาม ขายและให้บริการการปฏิบัติตามสัญญา
อีเมล (แพ็กเกจ A) หรือ Gmail ที่ใช้ติดตั้ง (แพ็กเกจ B)เปิดบัญชีและเข้าสู่ระบบการปฏิบัติตามสัญญา
สลิปโอนเงินและประวัติการชำระเงินยืนยันการชำระเงิน และเก็บเป็นหลักฐานทางบัญชีการปฏิบัติตามสัญญา / หน้าที่ตามกฎหมาย
ข้อมูลการใช้งานทางเทคนิค เช่น เวลาเข้าระบบ และบันทึกข้อผิดพลาดดูแลความปลอดภัยและแก้ปัญหาระบบประโยชน์โดยชอบด้วยกฎหมาย

เราไม่ขาย และไม่ส่งข้อมูลของลูกค้าให้ผู้อื่นเพื่อการตลาด

2. ข้อมูลผู้เช่าที่ลูกค้าบันทึกในระบบ

ตัวอย่างข้อมูล: ชื่อ เบอร์โทร เลขบัตรประชาชน ที่อยู่ ผู้ติดต่อฉุกเฉิน ข้อมูลบิล การชำระเงิน และรูปมิเตอร์

  • แพ็กเกจ A: ข้อมูลเก็บบนเซิร์ฟเวอร์ที่เราดูแล ลูกค้าเป็นผู้ควบคุมข้อมูล ส่วนเราเป็นผู้ประมวลผลข้อมูลที่ทำตามคำสั่งของลูกค้าเท่านั้น เราใช้ข้อมูลนี้เพื่อให้ระบบทำงานเท่านั้น และไม่เปิดดูข้อมูล เว้นแต่ลูกค้าขอให้ช่วยแก้ปัญหา หรือกฎหมายกำหนด
  • แพ็กเกจ B และ C: ข้อมูลอยู่ในบัญชีของลูกค้าเอง เราไม่ได้เก็บและเข้าถึงไม่ได้ ระหว่างช่วยติดตั้งผ่านการแชร์หน้าจอ เราจะไม่คัดลอกหรือบันทึกข้อมูลใด ๆ

3. สถานที่เก็บข้อมูลและผู้ให้บริการภายนอก

บริการใช้ทำอะไรที่ตั้งข้อมูล
Supabaseฐานข้อมูลและที่เก็บรูปของแพ็กเกจ Aศูนย์ข้อมูลประเทศสิงคโปร์
GitHub Pagesหน้าเว็บของระบบ (ไม่เก็บข้อมูลลูกค้า)ต่างประเทศ
LINEช่องทางติดต่อและรับสลิปตามนโยบายของ LINE

ข้อมูลแพ็กเกจ A จึงถูกเก็บนอกประเทศไทย ผู้ให้บริการเหล่านี้มีมาตรฐานความปลอดภัยและการเข้ารหัสข้อมูลระหว่างส่ง

4. การรักษาความปลอดภัย

  • เชื่อมต่อแบบเข้ารหัส (HTTPS)
  • แยกข้อมูลแต่ละบัญชีด้วยสิทธิ์ระดับฐานข้อมูล ลูกค้าแต่ละรายเห็นเฉพาะข้อมูลของตนเอง
  • แพ็กเกจ A เข้าระบบด้วยอีเมลและรหัสผ่าน ส่วนแพ็กเกจ B และ C เข้าด้วย PIN ที่ล็อกชั่วคราวเมื่อใส่ผิดหลายครั้ง

5. ระยะเวลาเก็บข้อมูล (แพ็กเกจ A)

  • รูปมิเตอร์: 12 เดือน แล้วลบอัตโนมัติ
  • ข้อมูลอื่นในบัญชี: เก็บตลอดที่บัญชียังอยู่ รวมถึงช่วงที่หมดอายุสมาชิก เพื่อให้ต่ออายุแล้วใช้ต่อได้
  • ลูกค้าขอให้ลบบัญชีและข้อมูลทั้งหมดได้ทุกเมื่อ โดยเราจะลบภายใน 30 วันนับจากวันที่ได้รับคำขอ
  • หลักฐานการชำระเงิน: เก็บตามระยะเวลาที่กฎหมายบัญชีและภาษีกำหนด

6. สิทธิ์ของเจ้าของข้อมูล

ลูกค้ามีสิทธิ์ขอเข้าถึง ขอสำเนา แก้ไข ลบ ระงับการใช้ คัดค้าน และขอโอนย้ายข้อมูลของตนเอง รวมถึงร้องเรียนต่อสำนักงานคณะกรรมการคุ้มครองข้อมูลส่วนบุคคล (สคส.)

ถ้าผู้เช่าต้องการใช้สิทธิ์เกี่ยวกับข้อมูลของตน ให้ติดต่อเจ้าของหอพัก (ผู้ควบคุมข้อมูล) โดยตรง เราจะช่วยเจ้าของหอพักดำเนินการตามคำขอ

7. กรณีข้อมูลรั่วไหล

ถ้าเกิดเหตุละเมิดข้อมูลในระบบแพ็กเกจ A เราจะแจ้งลูกค้าที่ได้รับผลกระทบโดยไม่ชักช้า เพื่อให้ลูกค้าในฐานะผู้ควบคุมข้อมูลแจ้ง สคส. ได้ภายใน 72 ชั่วโมงตามกฎหมาย

ส่วนที่ 3: ข้อความแนะนำให้เจ้าของหอใช้แจ้งผู้เช่า

หอพัก [ชื่อหอ] เก็บชื่อ เบอร์โทร เลขบัตรประชาชน ที่อยู่ และผู้ติดต่อฉุกเฉินของท่าน เพื่อทำสัญญาเช่า ออกบิล และติดต่อกรณีฉุกเฉินเท่านั้น ข้อมูลเก็บในระบบจัดการห้องเช่าที่มีการป้องกันการเข้าถึง และจะลบเมื่อสิ้นสุดการเช่าและหมดความจำเป็น ขอดู แก้ไข หรือลบข้อมูลได้ที่ [ช่องทางติดต่อหอ]
