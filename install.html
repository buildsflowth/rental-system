วิธีติดตั้งแอปบนมือถือ

ระบบจัดการห้องเช่า ติดตั้งเป็นแอปได้ฟรี ไม่ต้องผ่าน App Store / Play Store ใช้เวลาไม่ถึง 1 นาที

เปิดจาก LINEAndroidiPhone / iPadคอมพิวเตอร์คำถามที่พบบ่อย

💬ก่อนเริ่ม: ถ้าเปิดลิงก์จาก LINE

หน้าเว็บที่เปิดในแอป LINE / Facebook ติดตั้งเป็นแอปไม่ได้ ต้องเปิดในเบราว์เซอร์ก่อน

  1. กดปุ่ม ⋮ หรือไอคอนเข็มทิศ มุมขวาบน (หรือขวาล่าง)
  2. เลือก เปิดในเบราว์เซอร์ (Android จะเปิดด้วย Chrome · iPhone ให้เลือก Safari)
  3. ทำตามขั้นตอนของเครื่องคุณด้านล่าง

🤖Android (Samsung, OPPO, vivo, Xiaomi ฯลฯ)

ใช้แอป Chrome

  1. เปิดลิงก์ระบบของคุณใน Chrome
  2. หน้าเข้าสู่ระบบ กดปุ่ม ติดตั้งแอปลงเครื่อง (ถ้าไม่เห็นปุ่ม ให้กด ⋮ มุมขวาบนของ Chrome)
  3. เลือก ติดตั้งแอป หรือ เพิ่มลงในหน้าจอหลัก
  4. กด ติดตั้ง รอสักครู่ จะมีไอคอน "ห้องเช่า" บนหน้าจอ
  5. เปิดแอปจากไอคอน แล้วเข้าสู่ระบบ 1 ครั้ง ครั้งต่อไปเปิดใช้ได้เลย

🍎iPhone / iPad

ใช้แอป Safari (iOS 16.4 ขึ้นไป ใช้ Chrome ได้ด้วย)

  1. เปิดลิงก์ระบบของคุณใน Safari
  2. กดปุ่ม แชร์ ⬆︎ ด้านล่างจอ (iPad: มุมขวาบน)
  3. เลื่อนลง เลือก เพิ่มไปยังหน้าจอโฮม ＋
  4. เปิดสวิตช์ เปิดเป็นเว็บแอป (ถ้ามี) แล้วกด เพิ่ม มุมขวาบน
  5. เปิดแอปจากไอคอนบนหน้าจอ แล้วเข้าสู่ระบบ 1 ครั้ง
ไม่เห็นเมนู "เพิ่มไปยังหน้าจอโฮม": กด แก้ไขการทำงาน ท้ายรายการ แล้วเพิ่มเมนูนี้เข้ามา

💻คอมพิวเตอร์ (Windows / Mac)

ใช้ Chrome หรือ Microsoft Edge

  1. เปิดลิงก์ระบบของคุณ
  2. กดไอคอน ติดตั้ง ⊕ ทางขวาของช่องที่อยู่เว็บ หรือปุ่ม ติดตั้งแอปลงเครื่อง ในหน้าเข้าสู่ระบบ
  3. กด ติดตั้ง แอปจะเปิดเป็นหน้าต่างของตัวเอง และมีไอคอนบนเดสก์ท็อป/ทาสก์บาร์

❓คำถามที่พบบ่อย

ต้องเสียเงิน หรือโหลดจาก Store ไหม
ไม่ต้อง ติดตั้งจากหน้าเว็บได้ฟรี ไม่กินพื้นที่เครื่อง
ติดตั้งแล้วข้อมูลเดิมหายไหม
ไม่หาย ข้อมูลเก็บบนระบบออนไลน์ ใช้ได้หลายเครื่องพร้อมกัน เห็นข้อมูลเดียวกัน
ต้องอัปเดตแอปเองไหม
ไม่ต้อง แอปอัปเดตอัตโนมัติเมื่อเปิดใช้งาน ถ้าเห็นข้อความ "มีเวอร์ชันใหม่" ให้กดรีเฟรช
ลบแอปได้ไหม
ได้ กดค้างที่ไอคอนแล้วลบเหมือนแอปทั่วไป ข้อมูลในระบบไม่หาย ติดตั้งใหม่เมื่อไรก็ได้
ลิงก์ระบบของฉันคืออะไร
